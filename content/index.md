## 🗺️ Comment utiliser ce site ?

Ce site n'est pas un site classique, c'est un **graphe de connaissances**. Voici comment l'exploiter au mieux :

1. **La barre de recherche (en haut à droite) :** Tapez n'importe quel mot (ex: *Kepler*, *Convexe*, *Kant*) pour trouver toutes les fiches qui en parlent.
2. **Le Graphe (à droite) :** Cliquez sur les points pour voir comment les chapitres sont connectés entre eux.
3. **Les Backlinks (en bas de page) :** Ils vous montrent quelles autres pages font référence au concept que vous lisez.

> [!success] Astuce de révision
> Utilisez cet espace pour vos révisions actives : essayez de vous souvenir d'un théorème avant de cliquer sur le lien pour vérifier la réponse.
